# Global Instructions

- Never add "Co-Authored-By" lines or any co-author trailer to git commit messages.
- Do not use the `-m` flag with gsutil.
- "tmux command" means a command typed at tmux's command prompt (prefix + `:`), with no leading `tmux`, e.g. `switch-client -t gauth`. A command typed at the shell (`tmux switch-client -t gauth`) is a shell command; label it as one if you give it too.
